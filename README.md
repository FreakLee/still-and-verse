# Still & Verse

An English-first, interactive introduction to classical Chinese writing through everyday moments.

Choose a mood, explore an original line and its context, optionally add a photo, and download a shareable card. All photo processing happens in your browser. The English lines are new interpretive renderings for this prototype; each context panel links to the original text on Wikisource.

## Run locally

Open `index.html` in a browser. There is no build step, API key, or server.

## Publish with GitHub Pages

In this repository's **Settings → Pages**, select **Deploy from a branch**, `main`, and `/(root)`. The site is ready to publish directly from the repository root. `.nojekyll` is included.

This is a small, hand-curated prototype with two passages per mood. It does not analyze uploaded photos or store visitor data.
